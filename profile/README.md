# Karunagaran's Portfolio Website

## 📸 How to Add Your Profile Image

### Step 1: Prepare Your Image
1. Choose a professional profile photo (preferably square or portrait format)
2. Recommended dimensions: **350px × 350px** or larger
3. Supported formats: JPG, PNG, WebP, GIF

### Step 2: Add Image to Portfolio Folder
1. Place your image file in the same folder as `portfolio.html`
2. **Important:** Name your image file or note its exact filename (e.g., `my-photo.jpg`)

### Step 3: Update the HTML
1. Open `portfolio.html` with a text editor
2. Find this line (around line 80):
   ```html
   <img src="your-image.jpg" alt="Karunagaran" class="profile-img">
   ```
3. Replace `your-image.jpg` with your actual image filename
   - Example: `<img src="my-photo.jpg" alt="Karunagaran" class="profile-img">`
   - Example: `<img src="profile.png" alt="Karunagaran" class="profile-img">`

### Step 4: Save and View
1. Save `portfolio.html`
2. Open it in your browser
3. Navigate to the "About Me" section to see your image!

## 🎨 Image Features
- **Hover Effect:** Image moves up with enhanced shadow when you hover over it
- **Decorative Border:** Styled gold accent border (rotated for modern look)
- **Responsive:** Works perfectly on mobile, tablet, and desktop

---

## 💡 Image Tips
- **Best Results:** Use a clear, well-lit professional photo
- **Size:** Keep file size under 500KB for fast loading
- **Format:** PNG for transparency, JPG for smaller size
- **Aspect Ratio:** Square (1:1) works best with the design
